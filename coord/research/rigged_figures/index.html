Library figures moving

Dungine.v3, 3 October 2026. The library's rigged figures, moved by v2's own animation.

The library's figures now walk, run, cast, strike and fall in the game. v2 animates everyone with code (no animation files), and that code now drives the library's voxel figures without any changes. Hair, skirts, aprons and capes swing as they walk.
